# 🌿 VitaSênior — Movimento é vida

Treino fisioterapêutico personalizado para idosos. Alongamento, equilíbrio e respiração de forma simples e segura.

## 📋 Sobre o Projeto

VitaSênior é um aplicativo web desenvolvido como projeto universitário de **Impacto Social**, com foco em proporcionar exercícios seguros e personalizados para a terceira idade.

### Funcionalidades

- 🧘 Exercícios de alongamento
- ⚖️ Exercícios de equilíbrio
- 🌬️ Exercícios de respiração
- 📋 Treino personalizado baseado em avaliação de saúde
- ⏱ Cronômetro para descanso entre séries
- ✅ Rastreamento de progresso

## 🚀 Como Usar

1. Abra o `index.html` no navegador
2. Selecione seu perfil
3. Preencha a avaliação de saúde
4. Receba seu treino personalizado
